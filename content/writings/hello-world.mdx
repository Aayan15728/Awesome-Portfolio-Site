## How posts work

Every post is a single `.mdx` file inside `content/writings/`. The file name becomes the URL, so `hello-world.mdx` lives at `/writings/hello-world`.

Each file starts with a small block of frontmatter:

```md
---
title: "My post"
date: "2026-05-01"
summary: "One sentence shown in lists and link previews."
tags: ["nextjs", "notes"]
draft: false
---
```

Set `draft: true` to keep a post hidden in production while you work on it.

## What you can write

- Regular **Markdown**: headings, lists, [links](https://nextjs.org), and `inline code`.
- GitHub-flavoured extras like tables and task lists.

| Feature | Supported |
| ------- | --------- |
| Tables  | yes       |
| Lists   | yes       |

> Ship it, then make it better.

That's it. Add a file, commit, and it's live.
